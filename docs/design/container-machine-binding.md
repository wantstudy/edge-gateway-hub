# iot-daq 容器形态机器码绑定设计（对应计划 task 59 · 口径与 task 41 一致）

> 配套图：`docs/design/container-delivery.svg`。核心原则：**容器内机器码只来源宿主机**；容器重建 / 升级 ≠ 换机；宿主重装系统 = 换机（走后台废弃 + 重发）。

## 1. 宿主机指纹锚点方案（≥3 个宿主来源）

| 锚点 | 获取方式（容器内只读） | 说明 |
|------|----------------------|------|
| 宿主 machine-id | `--mount type=bind,src=/etc/machine-id,dst=/host/etc/machine-id,readonly` | 宿主 OS 安装期标识；宿主重装才变化 |
| 宿主 DMI product_uuid | `--mount type=bind,src=/sys/class/dmi/id/product_uuid,dst=/host/sys/dmi/product_uuid,readonly` | 主板 / BIOS 级硬件标识，随宿主硬件 |
| 宿主首个物理网卡 MAC | 安装脚本在宿主采集（排除虚拟 / veth 接口），写入只读指纹文件 | 见 §3 `host-fingerprint.json` |

- 指纹计算与裸机一致：多源锚点归一化 → 排序拼接 → HMAC-SHA256（厂商私密盐）→ 截断（task 41 算法）。
- **激活请求携带的机器码 = 宿主锚点组合哈希**；`anchor_hashes[5]` 中容器形态仅宿主侧锚点参与（容器内标识永远不参与，见 §2）。

## 2. 禁用容器内锚点的理由（红线）

| 容器内标识 | 问题 |
|-----------|------|
| 容器 `/etc/machine-id` | 由 runtime 在创建时生成——**每次 `docker rm && docker run` 都会变化** |
| 容器网卡 MAC | veth 对端随机分配，重建即变 |
| 容器主机名 | 默认 = 容器 ID，重建即变 |

**推演**：若以容器内标识为锚点 → `docker rm` 后重建容器 → 机器码变化 → ① 云端判定为「新设备」，**授权立即失效**，每次重建都要重新激活 / 重发激活码（`docker compose up --force-recreate` 即触发，完全不可运维）；② 更严重的是 **SQLCipher 本地库（HKDF 以机器码派生密钥，task 34）直接解不开**——历史数据永久不可读。

**结论**：容器内标识**一律禁用**为锚点；`device` 表也不因容器重建产生新记录（task 44：容器重建不触发换机重发）。

## 3. 锚点缺失降级（签名指纹文件）

- **场景**：精简宿主 / 受限内核导致 `/etc/machine-id` 不可读、DMI 不可访问。
- **方案**：安装脚本在宿主采集可用宿主信息（MAC、可能的 SMBIOS 序列号等），生成 **`host-fingerprint.json`（HMAC 签名）**，以只读方式挂载进容器；容器**只读该文件**，不自行采集。
- 签名密钥为厂商 / 安装器私密常量，防止现场伪造指纹文件冒充他机；文件随持久卷布局落位（见 `container-persistence-layout.md`）。

## 4. 与一机一码衔接（与 task 42 状态机一致）

| 场景 | 推演 | 结论 |
|------|------|------|
| 同宿主重建 / 升级容器 | 宿主锚点全部不变 → 机器码不变 | **同机**：租约与试用保持，不需重新发码 |
| 宿主更换网卡（合法运维） | 仅 MAC 一项漂移 → N-of-M 4/5 命中（task 41） | 仍判同机，不误伤 |
| 宿主重装系统 | `/etc/machine-id` 再生 + 可能换盘 → 命中 ≤3/5 | **判异机** → 走「总管理后台废弃 → 重发」换机流程 |

- 换机流程入口：客户端授权页仅可「申请换机」；废弃 / 重发仅厂商管理员经总管理后台执行（task 42 / 44，客户端无解绑入口）。

## 5. 口径对齐

- task 41：指纹算法、N-of-M 容错、锚点清单——容器形态是其宿主锚点子集，**口径完全一致**。
- task 42：宿主重装 → 换机状态机（废弃 → 重发 → 新激活）。
- task 44：`device.deploy_mode = docker` + `image_digest` + `host_anchor_ref`；容器重建不产生新 device 记录。
- task 34：SQLCipher 密钥 = HKDF(机器码)——机器码稳定性同时保护数据可读性。
