# iot-daq 容器持久卷布局设计（对应计划 task 59）

> 配套图：`docs/design/container-delivery.svg`。核心红线：**镜像可写层承载的业务 / 授权数据清单为「空」**——一切状态落宿主持久卷，使 `docker rm && docker run` 无法重置试用 / 租约。

## 1. 持久卷布局（/var/lib/iot-daq/）

```
/var/lib/iot-daq/                 ← 宿主命名卷或宿主绑定挂载（读写）
├── queue.db                      ← 队列库（rusqlite，独立于 telemetry）
├── telemetry.db                  ← 遥测库
├── config/                       ← 用户配置（点位表 / 北向出口 / 告警规则）
├── logs/                         ← 网关运行日志（本地轮转）
├── license/                      ← 授权凭证（Lease Token / 激活凭证，加密）
├── trial/                        ← 试用标记（多重冗余之一，加密）
└── host-fingerprint.json         ← 宿主指纹文件（安装脚本生成，HMAC 签名，只读语义）
```

| 数据类别 | 落位 | 说明 |
|---------|------|------|
| 授权 | `license/` | 凭证加密存储（对齐 task 41 存储保护），权限仅服务账户 |
| 试用 | `trial/` | 四重冗余之一（其余：库内记录 / 云端首激时间 / 备份位置，task 43） |
| 队列 | `queue.db` | 断网续传断点缓存，与授权无关但必须持久 |
| 配置 | `config/` | 客户配置；重建容器不丢 |
| 日志 | `logs/` | 本地轮转 + 外发由日志驱动管理 |

- **五类（授权 / 试用 / 队列 / 配置 / 日志）全部落宿主卷**；容器内路径与宿主路径一致挂载（`-v /var/lib/iot-daq:/var/lib/iot-daq`）。
- 镜像可写层承载的业务 / 授权数据清单：**空**（无任何条目）。

## 2. 镜像内不含敏感物清单

| 禁入项 | 理由 |
|--------|------|
| 私钥（签名 / HKDF 盐等机密） | 镜像可被导出解包（等同公开，task 43 前端/镜像不可保密同理） |
| 激活码 / Lease Token | 授权状态归设备与云端，不入分发物 |
| 宿主指纹 | 属于具体设备，导入时由安装脚本现场生成 |
| 默认口令 | 防止开箱即用弱凭据；首次初始化强制设置 |
| 客户配置 | 多客户共用镜像，配置现场注入 |

## 3. 重建语义推演（两条结论）

1. **同卷重建（`docker rm` 后以同一 `/var/lib/iot-daq` 卷 `docker run`）**：试用期、租约、授权凭证、队列与配置**全部保持**——机器码（宿主锚点）不变 + 本地状态在卷上；`restart: unless-stopped` 的日常重启更无影响。试用 / 租约**不被重置**。
2. **空卷重建（全新卷，模拟「换容器重置试用」）**：本地状态清零、视为新装；**但机器码 = 宿主锚点组合哈希，宿主指纹相同 → 云端识别为同一 device 记录**（task 44：不产生新 device、不触发换机重发），配合**云端首次激活时间**（task 23）交叉校验 → 试用倒计时以云端首激时间兜底，**「换容器重置试用」不成立**。

> 极端场景（宿主整机更换 + 全新卷）与「换机」同路径：走总管理后台「废弃 + 重发」（task 42），商业上可接受并全程审计。

## 4. 运行时约束（与部署参数联动）

- 卷挂载：`-v /var/lib/iot-daq:/var/lib/iot-daq`（读写）；锚点文件单独**只读**挂载（见 `container-machine-binding.md`）。
- `restart: unless-stopped`；`--memory / --cpus` 资源限制；日志驱动本地轮转（容器 stdout 与 `logs/` 双轨）。
- 权限：容器内进程非 root 运行为目标；`logs/`、`config/` 目录权限仅限服务账户。

## 5. 口径对齐

- task 23：云端首次激活时间（试用兜底）。
- task 34：SQLCipher 库文件在卷上，密钥派生自机器码（宿主锚点）。
- task 41 / 43：宿主锚点方案与「可写层不含授权状态」红线同源。
- task 44：`device` 记录 `deploy_mode` / `image_digest`；容器重建不产生新 device。
