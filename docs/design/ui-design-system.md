# IoT-DAQ 界面设计系统（UI Design System）

> 适用对象：网关侧 `web-console/`（Windows Tauri WebView + Linux/容器浏览器访问）与厂商侧 `admin-console/`
> 状态：Wave 0 设计产物，待用户确认后冻结为 v1
> 配套：`ui-gateway-console.md`（客户端界面）、`ui-admin-console.md`（管理后台界面）、`prototype/iot-daq-ui-prototype.html`（可点击高保真原型）

---

## 1. 定案决策（需要用户确认的点已标注）

| 项 | 决策 | 理由 |
|---|---|---|
| 组件库 | **两套应用统一 Arco Design Vue**（Vue 3 + TS） | 团队现有项目（aiguild-admin）已在用 Arco，学习成本为 0；替换 task 27 原定的 Element Plus，避免**两套设计语言 + 两套组件库**的双份维护成本。若倾向 Element Plus，替换成本为机械性的（仅需换组件前缀与主题变量） |
| 共享层 | 新增 `ui-kit/`（npm workspace 包）：设计 token + 通用业务组件 | 两个应用是两个独立构建产物，但**视觉与交互必须一致**；共享包是唯一能保证不漂移的方式 |
| 应用分离 | `web-console` 与 `admin-console` **代码、构建、部署完全分离** | 沿用 task 47 硬约束：管理后台不得与网关侧混为同一构建产物 |
| 主题 | **首期仅浅色主题**；侧边导航亦为浅色（白底 + 细边框） | 与「首期不做深色/多语言」一致；浅色在车间办公区与客户演示环境中观感更稳 |
| 目标分辨率 | **≥1366×768**，主设计基准 1440×900 | 工业现场常见工控机/笔记本分辨率偏低；不做移动端适配 |
| 字体 | 系统字体栈 + **数字等宽**（`font-variant-numeric: tabular-nums`） | 数值列必须对齐，否则实时监控表抖动不可读 |
| 表格密度 | **紧凑为主**（行高 40px），可选舒适（48px） | 一屏多看几行是运维刚需；点位表动辄数百行 |

## 2. 设计 Token

### 2.1 色彩

**品牌与中性**

| Token | 值 | 用途 |
|---|---|---|
| `--brand` | `#1F6FEB` | 主按钮、选中态、链接 |
| `--brand-hover` | `#3B82F6` | 悬停 |
| `--brand-active` | `#1A5FD0` | 按下 |
| `--brand-subtle` | `#E8F1FE` | 选中行底色、标签底 |
| `--text-1` | `#1D2129` | 主文本、表头 |
| `--text-2` | `#4E5969` | 次级文本、表单标签 |
| `--text-3` | `#86909C` | 占位符、辅助说明 |
| `--border` | `#E5E6EB` | 边框、分割线 |
| `--divider` | `#F2F3F5` | 弱分割 |
| `--bg-app` | `#F7F8FA` | 页面底色 |
| `--bg-card` | `#FFFFFF` | 卡片/表格 |
| `--bg-hover` | `#F7F8FA` | 行悬停 |

**语义状态色（工业设备语境，与股市配色无关）**

| Token | 值 | 语义 | 使用场合 |
|---|---|---|---|
| `--ok` | `#00A870` | 正常 / 在线 / 已授权 / 已绑定 | 设备在线、心跳正常、租约有效 |
| `--warn` | `#FF7D00` | 告警 / 降级 / 宽限期 / 试用中 | 试用剩余、队列高位、回执跳空、安全模式 |
| `--danger` | `#F53F3F` | 故障 / 离线 / 已冻结 / 危险操作 | 设备离线、授权失效、废弃激活码 |
| `--info` | `#1F6FEB` | 提示 / 信息 | 说明性横幅 |
| `--unknown` | `#86909C` | 未知 / 未激活 / 已禁用 | quality=unknown、未连接、已停用 |

规则：
1. **颜色不是唯一信号**：每个状态色必须同时配图标或文案（色盲/车间强光下不可辨）。
2. **危险操作按钮**用 `--danger`，且必须二次确认（见 §5）。
3. 试用、宽限、降级这类**时间相关状态**统一用 `--warn`，不与故障红混用，避免客户误判为故障。

### 2.2 尺度

| Token | 值 |
|---|---|
| 间距梯度 | 4 / 8 / 12 / 16 / 24 / 32 px |
| 圆角 | 控件 4px，卡片 8px，标签 4px（胶囊 999px 仅用于状态标签） |
| 字号 | 页标题 20 / 区块标题 16 / 正文 14 / 表格 13 / 辅助 12 |
| 行高 | 正文 22px，表格 20px |
| 行高（表格） | 紧凑 40px / 舒适 48px |
| 阴影 | 卡片无阴影（用 1px 边框），浮层 `0 4px 16px rgba(29,33,41,.08)` |
| 侧边导航 | 展开 240px / 折叠 64px |
| 顶栏 | 56px |
| 内容区 | 最大 1600px，左右内边距 24px |

### 2.3 布局骨架

```
┌────────────┬─────────────────────────────────────────────────────┐
│            │ 顶栏 56px：应用标识｜全局横幅槽｜角色切换｜账号菜单   │
│  侧边导航   ├─────────────────────────────────────────────────────┤
│  240px     │ 页头：面包屑 · 页面标题 · 说明 · 右侧主操作按钮      │
│  分组菜单   ├─────────────────────────────────────────────────────┤
│            │ 内容区：状态横幅 → KPI → 主体（表格/表单/图）        │
│  底部：版本  │                                                     │
└────────────┴─────────────────────────────────────────────────────┘
```

- **全局横幅槽**（顶栏下方整宽）：承载授权/降级类全局状态（试用剩余 ≤2 天、租约超期、只读模式、安全模式）。同一时刻只显示最高优先级一条，其余折叠为「+N 条」。
- 侧边导航按**运维动线**分组，不按技术模块分组（见两个界面文档的信息架构）。
- 页面「主操作」固定右上角，同页只允许**一个**主按钮。

## 3. 共享业务组件（`ui-kit/`）

| 组件 | 说明 | 关键约束 |
|---|---|---|
| `StatCard` | KPI 卡：标签 + 大数值 + 单位 + 环比 + 迷你趋势 | 数值等宽字体；环比升降用箭头 + 文案，不单靠颜色 |
| `StatusTag` | 状态标签：`在线/离线/降级/试用/已授权/已绑定/已废弃/已重发/未激活` | 每个状态固定色 + 固定文案，禁止各处自造同义词 |
| `MachineCodeDisplay` | 机器码展示：`8F3A-91C2-7D04-5BE6` 分段显示 + 一键复制 + 来源分解（锚点列表） | 只读，禁止可编辑；复制按钮给出「已复制」反馈 |
| `CodeLifecycleTimeline` | 激活码生命周期时间线（发放 → 绑定 → 废弃 → 重发 → 再绑定） | 每步带时间、操作者、原因、关联码 |
| `DeviceStateDot` | 设备连接状态点 + 文案（在线/离线/重连中/采集失败） | 必须带文案，不能只有圆点 |
| `QueueGauge` | 环形/条形水位：磁盘队列 vs 10GB 上限、内存队列 vs 水位线 | 超高水位转 `--warn`，逼近上限转 `--danger` |
| `QualityBadge` | 质量码：`Good / Uncertain / Bad / Timeout / Unknown` | 与 task 53 的 quality 枚举一一对应，前端不得自造 |
| `EncodingRadio` | 北向编码选择：`protobuf`（默认）/ `json`，选 JSON 时**内联展示精度与性能提示** | 文案固定：「超出 2^53−1 的整数将编码为字符串」 |
| `DangerConfirmModal` | 危险操作确认：标题 + 影响清单 + **必填原因** + 输入操作对象名称二次校验 | 用于废弃激活码、删除设备、恢复出厂、强制回滚配置 |
| `PointTableEditor` | 点位表：行内编辑 + 批量导入/导出 + 校验结果面板 | 大数据量虚拟滚动；导入错误行号定位 |
| `LogViewer` | 日志查看器：分级过滤 + 关键字 + 实时跟随 + 导出 | 实时跟随可暂停，暂停后不得自动滚动抢焦点 |
| `DiagPanel` | 诊断面板：二进制自检、锚点来源、串口权限、时钟偏差、队列水位 | 只读展示 + 「导出诊断包」 |
| `RoleGate` | 角色可见性控制：按角色隐藏/禁用菜单与按钮 | **仅控制可见性，不承担授权判定**（判定在 Rust 侧与后端） |

## 4. 交互约定

### 4.1 全局
- **保存语义**：表单页采用显式「保存」按钮，不做隐式自动保存；离开有未保存改动的页面必须拦截确认。
- **提交反馈**：按钮进入 loading 并禁用，成功用轻提示（toast，3s），失败保留表单内容并在字段旁给出行内错误。
- **破坏性操作**：一律 `DangerConfirmModal`，且确认按钮文案必须是动词短语（「废弃激活码」而非「确定」）。
- **空态**：空态必须给下一步动作（如点位表为空 → 「导入点表」+「手工新增」两个入口）。
- **错误态**：给出「发生了什么 + 怎么解决」，禁止只显示错误码；网络类错误带「重试」。

### 4.2 实时数据
- 实时数值走 WS（task 52），**断连时页面顶部出现 `--warn` 细条**：「实时通道已断开，数据停止刷新（最后更新 12:31:40）」+ 重试按钮。
- 数值变化的视觉反馈：变化方向用箭头（↑/↓）+ 数值色（升 `--ok` / 降 `--brand`，此处**不代表好坏**，仅表示变化方向）；超过 1s 未更新则该行变灰（陈旧标记）。
- 高频刷新默认 **1s 节流**渲染，避免 200 设备 × 100ms 直接把浏览器打满（这是前端性能硬约束，写入 task 29 验收）。

### 4.3 授权与防破解相关（本项目最高优先级域）
- **授权状态永远可见**：顶栏右侧常驻授权状态胶囊（`试用 2 天` / `已授权 · 2027-09-23 到期` / `已降级`），点击进入授权页。
- **降级必须可解释**：任何降级/停发都必须在横幅中说明原因与恢复路径（例：「云端心跳超期 7 天，北向转发已停用；本地采集继续运行。请检查网络或联系厂商。」）。
- **客户端不提供废弃/解除绑定入口**：授权页只提供「复制机器码」「输入激活码激活」「申请换机」（提交工单给厂商），**没有**「解除绑定 / 更换机器码 / 重置试用」。
- 授权判定结果只由 Rust 侧/后端给出，前端 `RoleGate` 仅做可见性；前端代码中不得出现授权分支（task 50 验收项）。

## 5. 文案规范（工业现场，避免歧义）

| 场景 | 使用 | 禁止 |
|---|---|---|
| 未授权超期停发 | 「北向转发已停用，本地采集继续」 | 「系统已停止」「授权失败」 |
| 试用期 | 「试用剩余 2 天 14 小时」 | 「剩余 62 小时」（现场要天数） |
| 队列积压 | 「磁盘队列 3.2 GB / 10 GB，预计可续传 4.1 天」 | 「队列水位 32%」 |
| 编码切换 | 「该出口使用 JSON 编码；超出 2^53−1 的整数将以字符串输出」 | 「性能可能下降」（无量化不给结论） |
| 拒绝原因 | 明确枚举文案（`签名无效` / `时间超出窗口` / `重复消息` / `机器码不匹配`） | 「校验失败」 |

时间统一显示 `YYYY-MM-DD HH:mm:ss`（本地时区）+ 悬停显示 UTC 与相对时间（「6 分钟前」）。

## 6. 无障碍与现场适配

- 文本对比度 ≥ 4.5:1；状态标签底色为浅色系 + 深色文字（不用深底白字）。
- 全键盘可达，焦点环可见（`2px var(--brand)`）；弹窗焦点锁定并可用 Esc 关闭（危险确认弹窗除外，需显式选择）。
- 点击区域最小 32×32px；表单控件最小高度 32px。
- 页面可用 `Ctrl+F` 浏览器搜索定位表格内容（避免虚拟滚动隐藏 DOM；大数据表提供「搜索框」替代）。

---

## 7. 明确不做（首期）

- 深色主题、多语言（i18n）、移动端/平板适配。
- 自定义主题编辑器、拖拽式仪表盘编排。
- 任意前端图表拖拽分析（历史报表为 P2 的 DuckDB 领域）。
- 任何在前端实现的授权/防篡改判定。
