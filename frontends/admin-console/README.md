# admin-console — 厂商总管理后台

厂商运营后台：激活码发放 / 绑定 / 废弃 / 重发（换机工单 ≤3 次点击）、设备与租户管理、回执与异常、签名密钥轮换、审计日志等 10 页面。

**当前状态**：目录占位，由 **Wave 6 task 47** 初始化（Vite + Vue 3 + TypeScript + Arco Design Vue + `ui-kit/`），本阶段不引入任何前端依赖。

关键约束（设计定稿）：

- 废弃弹窗四要素：影响清单 / 原因必填 / 补充说明 / 对象名二次校验
- 重发支持预绑定与留待激活两种模式，展示溯源关系
- 「异常 ≠ 破解」：设备页无「一键判为破解」动作，只能标记异常（备注）并转人工
- 所有写操作走管理 API（`/admin/*`），前端无私钥、无本地状态伪造
