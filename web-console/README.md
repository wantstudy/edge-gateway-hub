# web-console — 网关侧管理界面

工业网关本机管理界面：设备接入 / 点位与映射 / 实时监控 / 北向转发 / 授权与激活 / 日志审计 / 诊断自检等 14+ 页面。

**当前状态**：目录占位，由 **Wave 4 task 27（Vue 界面骨架）** 初始化（Vite + Vue 3 + TypeScript + Arco Design Vue + `ui-kit/`），本阶段不引入任何前端依赖。

关键约束（设计定稿）：

- 实时数值刷新节流 1s（200 设备场景保护浏览器）
- 客户端**只提供**「复制机器码 / 输入激活码 / 申请换机」三个授权触点，**无**废弃 / 解绑 / 重置试用入口
- 三角色 RBAC（admin / operator / viewer），前端仅控制可见性，判定在后端与 Rust 侧
- 点位表 CSV/XLSX 批量导入导出，校验给出「行号 + 原因 + 允许值」
