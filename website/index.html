SPEC // CORE FEATURES

核心特性

面向工业现场的全栈数据采集解决方案

SPEC-01采集层

多协议采集

支持 Modbus TCP / RTU、OPC UA 等主流工业协议，覆盖 PLC、仪表、传感器等设备。

SPEC-02转发层

北向转发

MQTT（v3.1.1 / v5）发布，每路独立 protobuf / JSON 编码，适配各类云平台。

SPEC-03韧性

本地韧性

断网续传（SQLite 队列）、背压控制，确保数据不丢失、网络恢复后自动补传。

SPEC-04边缘计算

规则与公式

点位级计算、告警规则灵活配置，边缘侧完成数据预处理与阈值判断。

SPEC-05管理面

Web 控制台

设备 / 点位 / 转发 / 告警 / 审计全功能管理，本地访问 http://127.0.0.1:9012。

SPEC-06安全面

安全设计

最小权限容器（非 root、只读根文件系统、cap_drop ALL），降低攻击面。

DEPLOY // DOCKER

Docker 部署

镜像已内置授权服务地址（无需任何配置），host 网络运行；端口 9011 为 API，9012 为 Web 控制台，数据持久化于 /data/edge-gateway。

docker run -d --name edge-gateway-hub --network host --restart=always -v /data/edge-gateway:/var/lib/iot-daq:rw -v /etc/machine-id:/host/etc/machine-id:ro -v /sys/class/dmi/id:/host/sys/class/dmi/id:ro -e TZ=Asia/Shanghai wantstudy/iot-daq-gateway:0.2.0
docker-compose.yml — 编排 
services:
  edge-gateway-hub:
    image: wantstudy/iot-daq-gateway:0.2.0
    container_name: edge-gateway-hub
    network_mode: host
    restart: always
    environment:
      - TZ=Asia/Shanghai
    volumes:
      - /data/edge-gateway:/var/lib/iot-daq:rw
      - /etc/machine-id:/host/etc/machine-id:ro
      - /sys/class/dmi/id:/host/sys/class/dmi/id:ro

RUNBOOK // QUICK START

快速开始

三步完成部署，从安装到数据上云

  1. STEP 01

    下载并安装

    运行 Windows 安装包，或拉取 Docker 镜像启动容器。

  2. STEP 02

    配置设备与点位

    通过 Web 控制台（http://127.0.0.1:9012）添加设备、点位和转发规则。

  3. STEP 03

    启动采集

    数据自动采集、缓存、转发至 MQTT 平台。
